问题 1：Python变量和数据类型

请编写一个Python程序，完成以下任务：

  1. 定义一个名为 name 的字符串变量，赋值为你的名字
  2. 定义一个名为 age 的整数变量，赋值为你的年龄
  3. 定义一个名为 is_student 的布尔变量
  4. 使用 print() 函数输出这些变量的值

示例代码：

# 定义变量
name = "袁佳琪"
age = 20
is_student = True

# 输出变量
print("姓名:", name)
print("年龄:", age)
print("是否学生:", is_student)
